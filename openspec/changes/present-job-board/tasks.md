# 前端实施任务

## 1. 视觉与岗位卡

- [x] 1.1 接入设计变量、MiSans 字体资源与「设置 → 关于」署名。核对中文、英文、数字、表单和 400/600/650 字重的实际渲染，并检查回退后的可读性。
- [x] 1.2 用设计基底中的四份虚构岗位制作桌面横向进展卡，在常用宽屏、中间窗口和 1024px 核对密度、星标、实际节点及加粗时间。新看板打开时为零条记录。
- [x] 1.3 接上添加岗位、星标和资料编辑，分别用单个链接、公司＋职位录入。补全资料后验证原链接仍能打开，取消星标恢复普通排序。

## 2. 进展与结果操作

- [x] 2.1 在卡上接入当前环节和新增进展动作。用二面标记已面、完成笔试、从一面直接登记 OC 或书面 Offer 核验每次只更新用户选定的内容。
- [x] 2.2 接入历史更正、逐步撤回、已挂与已拒的登记、更正和清除。验证编辑一面后仍显示最新二面、已挂与二面并列、撤回唯一节点后仍能找到该岗位。

## 3. 手机历史与操作区

- [x] 3.1 用同一组数据保留点击展开、左右滑动两种可操作的手机候选。分别验证初始位置为最新、可回到最新、回看一面时更新动作仍指向二面。
- [ ] 3.2 在 iOS、Android 真机上连续找岗位、看历史、更新二面和返回列表，对比斜滑、展开后的位置、菜单及软键盘遮挡。将实际表现和选定的历史方式、菜单容器记入设计基底。
- [ ] 3.3 将选定交互接入正式页面。核对 320、390、430px 和中间窗口下长名称、多轮节点、44px 触控目标、键盘焦点、读屏按钮名称及普通文字对比度。

## 4. 开始页、保存与主屏幕入口

- [x] 4.1 接入岗位进展与近期安排模块，按记录派生面试、笔试截止和 Offer 答复期限。用仅日期、标记已面、申请结束与恢复验证内容随记录变化。
- [x] 4.2 接入开始页偏好，验证模块显隐和顺序可保存、手机专属顺序可恢复为共用、桌面偏好独立。
- [x] 4.3 对接两个存储适配器的保存和备份反馈。验证已打开的本地版断网写入、明确失败、Sites 提交后丢失响应、过时撤回、导出 JSON 及向空板和非空板导入的实际结果。
- [ ] 4.4 添加主屏幕所需的 manifest、图标、启动地址和平台操作指引。在支持的 iOS、Android 浏览器通过系统操作添加，验证从图标能进入对应看板。
